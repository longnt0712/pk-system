# Perry pet

Perry uses the image supplied by the user, preserving the character's face, hat, pose, teal body and orange features. `reference-original.png` preserves the upload; `reference-transparent.png` removes only the connected outer background, retaining enclosed white eye details. `pet-level-4.svg` embeds that transparent raster and centers it in a square canvas. The runtime `pet-level-4.png` is a transparent 1024 × 1024 RGBA render; enlarging the supplied 152 × 203 image does not add source detail.

Perry unlocks fully formed at vocabulary level 4. There are no intact or cracked egg stages. The selection key is `CUTE_PERRY`; administrators can select Perry at level 0 through the existing admin access rule.

The Lụm Trứng reward identifier is 21, separate from the vocabulary unlock level. `battleRewardReferenceLevel: 2` gives Perry exactly the same draw chance and points as the hatched Mầm Học reward. Reward metadata supplies Perry's label and artwork directly.
